# Competitive Programming Templates 🏁

This repository contains my daily-use templates in **C++** throughout my competitive programming journey.

## 📂 Content

### *Number Theory*

* Prime checking
* Divisors
* GCD & LCM
* Sieve
* Mod inverse
* Prime factors
* Factorial with mod
* Fast power & Mod power
* SPF (Smallest prime factor)
* Combinatorics (combination and permutation)

### *Graph Theory*

* BFS & DFS
* DFS implementatin in details
* BFS implementatin in details
* Dijkstra
* Floyed
* Bellman
* Kruksal
* Kth Ancestor

* Merge Sort Tree
* Sparse Table

### *General*

* Prefix & 2D Prefix & Partial & 2D Partial Sums
* Merge Sort
* Bits
